# sales-data-warehouse

Welcome to the **Sales Data Warehouse project** repository!
A SQL Server data warehouse project built from a raw sales CSV, covering staging, dimensional (star schema) modeling, ETL pipelines, and data quality validation. Built as a portfolio project, with an emphasis on getting  the modeling decisions and data cleaning right, not just making the pipeline run.

---

## Project Requirements

### Building the sales data warehouse

#### Objective
Develop a sales data warehouse using SQL server to consolidate sales data, enabling analytical reporting and informed decision-making.

#### Specifications
- **Data Sources**: Import sales data provided as a CSV file.
- **Data Quality**: Cleanse and resolve data quality issues prior to analysis.
- **Integration**: Integrate the source data into user-friendly data model designed for analytical queries.
- **Scope**: Focus on the latest dataset only, historization of data is not required.
- **Documentation**: Provide clear documentation of the data model to support both business stakeholders and analytics teams
